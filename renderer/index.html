Lead Developer & Creator
Chamika Sandeepa
Developed with dedication by Chamika Sandeepa. A blazing-fast, lightweight, portable local web hosting stack for Windows developers.
Multi-PHP Runtime
1-click downloaders for official PHP 8.1 - 8.5 with pre-configured extensions (curl, mysqli, pdo, gd, mbstring, openssl, zip) and dedicated AppData storage.
NGINX Web Server
Port 80 & 443 reverse proxying with automated virtual host config generation. Access local projects directly using clean project.test domains.
MySQL / MariaDB Server
Native Windows MySQL service detection (Port 3306) and 1-click portable MariaDB 11.4 LTS with complete database manager & ER diagram tool.
Cloudflare Tunnel & Mail
Share local web projects instantly to the public web with Cloudflare Tunnels, plus a built-in SMTP Mail Catcher to test outgoing emails.
